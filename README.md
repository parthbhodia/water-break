# Water Break

Hydration reminder and water tracker for Chrome (Manifest V3).

- Gentle on-page reminder card with one-tap logging and snooze
- Daily goal and cup size in ml, quick add, 7-day history and goal streak
- Reminder weekdays, quiet hours, light/dark theme, guided tour
- 19 languages, no accounts, no tracking, no network requests

Website, support and privacy policy: https://parthbhodia.github.io/water-break/

## Develop

Load this folder unpacked at `chrome://extensions` (Developer mode on).

Store assets: `python store-assets/build.py` (screenshots and promo tiles),
`python store-assets/make_icons.py` (icons), `python store-assets/package.py` (upload zip).
